## Prompts finales

Se ejecutó una generación por icono, con fondo transparente y la misma referencia adjunta. Cada prompt combina el bloque común con su bloque de sujeto.

### Bloque común

Use case: stylized-concept. Asset type: a single isolated premium 3D icon for BY HEVËN process cards. Input image is STYLE REFERENCE ONLY: emulate the dimensional pearlescent white objects with pale cool blue/lavender details in the lower right of the three EMYASA cards. Do not reproduce the web page, cards, text, or blue/green backgrounds. Style: high quality clean 3D product render, soft rounded ceramic/clay forms, subtle realistic bevels and ambient occlusion, pearly satin white body, very pale icy lavender-blue inset details, tiny brushed silver accents. Consistent fixed three-quarter front view, front dominant, top and right side slightly visible, soft studio key light from upper left, gentle blue-violet rim. Object centered in a square with 14% transparent clear margin all around. A faint local contact shadow only, fully transparent background. Large readable silhouette, limited detail, tactile physical volume, sophisticated not cartoonish. No letters, no words, no logos, no UI card, no ground plane, no floating fragments, no saturated colors, no purple background.
